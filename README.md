# Autonomic Tracker

A local-first symptom tracker designed for people managing autonomic dysfunction, post-exertional malaise (PEM), chronic illness, fluctuating energy levels, and complex symptom patterns.

This project was originally built for personal use and evolved through real-world daily tracking and iteration.

---

## Why This Exists

Many symptom trackers either:

- Require accounts and cloud storage
- Collect more information than necessary
- Focus on medical record keeping rather than pattern recognition
- Create significant cognitive load during periods of illness

Autonomic Tracker was built around a different philosophy:

- Fast daily entry
- Low cognitive overhead
- Local-first privacy
- Pattern tracking over perfect record keeping
- Designed by someone actually using it

---

## Features

### Daily Tracking

- Symptom severity tracking
- Symptom notes
- Fluid intake
- Urine output
- Number of urinations
- Electrolyte packet tracking
- Sleep quality
- Energy level
- Upright tolerance
- Overall symptom burden

### Vital Sign Logging

Up to three optional readings per day:

- Time
- Blood pressure
- Heart rate
- Temperature
- Context (resting, upright, after activity, symptomatic, etc.)

### Activity Tracking

- Physical exertion
- Cognitive exertion
- Social/sensory exertion
- Delayed worsening / PEM timing

### Cycle Tracking

- Estimated cycle day
- Cycle phase
- PMDD severity
- Notes

### Trend Analysis

The app can highlight changes from your recent baseline, helping identify symptom shifts that may be worth investigating.

Examples include:

- Increased fatigue
- Increased lightheadedness
- Reduced energy
- Reduced upright tolerance

These indicators are observational only and are not diagnostic.

### Export Options

- JSON backup
- CSV export
- AI-friendly Markdown export

The AI export was specifically designed for upload into AI systems for pattern analysis and discussion.

## Data Privacy

### Local-First Design

All data remains on the user's device.

The project intentionally does **not** use:

- User accounts
- Cloud databases
- Server-side storage
- Analytics
- Tracking

The creator cannot see, access, collect, or recover user data.

Unless a user manually exports and shares their own information, all health data remains stored on the user's device.

### Backups

Users are responsible for their own backups.

Regular use of the JSON export feature is strongly recommended.
